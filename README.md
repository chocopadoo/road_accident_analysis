# Road Accident Analysis

## Project Overview

This project analyzes road traffic accidents to identify patterns related to crash timing, weather conditions, crash types, and contributing factors. The goal is to discover key insights that can help improve road safety and reduce accident risks.

## Tools Used

1. Python
2. Pandas
3. Plotly
4. Jupyter Notebook

## Analysis

The project explores:
1. Crash patterns by hour and day of week
2. Most common crash types
3. Main contributing factors
4. Weather conditions and crash frequency
5. Factors associated with fatal crashes

## Key Insights

1. The highest number of crashes occurred between 15:00 and 17:00.
2. Saturday had the highest number of recorded crashes.
3. Traffic violations were among the main contributing factors.
4. Angle crashes resulted in the highest number of fatal injuries.

## Conclusion

This analysis helps identify patterns in road accidents and provides insights into factors that influence crash frequency and severity.
